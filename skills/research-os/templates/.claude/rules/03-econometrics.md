# Econometric work

- State the estimand before selecting an estimator.
- Document unit, timing, treatment/exposure, comparison, target population, assumptions, fixed effects, clustering, weights, and sample.
- Avoid post-treatment controls and future leakage unless explicitly justified.
- Treat pre-trends as diagnostics with power limits, not proof.
- Use current estimators appropriate to staggered timing and heterogeneous effects.
- Distinguish primary, robustness, exploratory, and mechanism analyses in both code and outputs.
