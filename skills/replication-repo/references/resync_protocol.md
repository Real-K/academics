# 저장소 재조립·동기화 프로토콜

1. 조립 스크립트는 **`.git` 과 수기 문서(README·DATA_ACCESS·LICENSE·.gitignore)를 보존**하고 나머지만 지운 뒤 재생성한다. 처음 버전은 `rmtree` 로 `.git` 까지 지울 수 있었다 — 반드시 KEEP 집합을 둔다.
2. 수기로 한 익명화(주석 속 회사명 등)는 **조립 스크립트 안에 내장**한다. 안 그러면 재조립 때 되살아난다.
3. 노트북 셀은 표·그림 빌더 스크립트를 **마커 기준으로 잘라 원문 그대로** 넣는다(재작성 금지). 마지막 셀이 `paper_exhibits/` 와 대조하고 어긋나면 `assert` 로 빌드 실패.
4. 동기화 트리거: 분석 코드·산출물·표/그림 빌더·전시물 중 하나라도 바뀌면. 커밋 메시지에 무엇이 바뀌었고 검사 결과(표 N 동일·그림 N 동일·원장 N행 해석)를 적는다.
5. 푸시 후 `gh api repos/<owner>/<repo>/contents` 로 실제 내용을 확인한다(size 필드는 지연된다).
6. **익명심사 중에는 실명 저장소를 투고본에 링크하지 않는다.** 게재 후 링크. DOI 가 필요하면 Zenodo 스냅샷.
