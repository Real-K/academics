# 설계 레버 체크리스트 — 결과가 약해졋을 때 순서대로 검토한다

각 레버는 두 논문에서 실제로 결과를 바꿨거나(✓) 바꾸지 못했음을(✗) 정직하게 보인 것이다. **모든 레버의 결과를 기록**한다.

## A. 반사실(대조군) 구성
1. **조절변수 균형 매칭** — 이질성을 볼 조절변수를 매칭 셀에 넣는다. P-014: 상태 3분위를 셀에 추가 → gradient 0.48→0.71 (z 2.19→3.96). 진단: 대조군의 자기 결과를 처치기업의 조절변수에 회귀 → 유효 반사실이면 0 (0.311→0.035).
2. **거울 위약(mirror placebo)** — 모든 대조기업을 유사처치로 삼아 **동일 절차**로 자기 대조군에 매칭 → 귀무분포(P-014: 1,246건). 귀무가 0 이 아님을 보이는 것 자체가 방어.
3. **clean pool 통일** — 대조 풀에서 처치·유사처치 전부 제외(P-016 wp13c: 잃은 검정력 회복).
4. **공통표본 검정** — 설계 A/B 를 같은 사건에서 비교해 "표본 구성 vs 설계" 를 분리.

## B. 표본
5. **표본 회수** — 식별자 결측 기업을 기업명 매칭으로 회수(P-014: 283→379). 회수 기업은 대조 풀에서 제외(오염). 회수 뒤 **기각했던 설계 전부 재점검**.
6. **창 완비 요건 완화** — ≥6/12개월 등(P-014 F.1: +24건, 회수분 반응이 더 작아 정직 보고).
7. 집계 수준(월→분기)·지평(12/24/36) 감도.

## C. 결과변수·변환
8. **비율 분모 오염 검정** — 분자만(log count) / 분모 통제 / 분모만 — "denominator artefact 아님" 방어.
9. **0 을 살리는 변환** — asinh, log1p (탈락 표본이 결론을 만드는지).
10. **암묵 채용** max(0, ΔE + S) 등 기록 오류에 덜 민감한 대체 측정.
11. **결과대상 배터리 + 쌍대비** — 같은 사건에서 A−B (분산 축소; P-014 채용−고용 +0.754, z 4.56).
12. **결합 검정** — 결과 벡터의 Mahalanobis 거리 RI (개별로 약한 것이 패턴으로 강함).

## D. 추론
13. **위약 귀무 기반 p + 부트스트랩 CI 둘 다** (귀무 범위를 추정치 CI 로 쓰지 않는다).
14. **균일 밴드(sup-t)·다중성 보정(max-|t|)** — 문턱 격자 결과에(P-016).
15. **HonestDiD 상대크기 M̄** — 사전추세를 "없다"가 아니라 "얼마까지 견딘다"로.
16. **비중첩 사전추세** — 상태 창과 결과 기준창이 겹치면 기계적 상관 → 창을 분리해 재추정(P-014 I-66).
17. 꼬리 규약 — 방향 가설은 상단꼬리, 비방향은 양측. **원고 전체 한 규약 + 라벨**.

## E. 추정대상·서사
18. **estimand 재정의** — 평균효과가 아니라 이질성 gradient 가 논문의 대상이 될 수 있다(P-014 의 전환).
19. **moderator → mediator** — 조절이 안 나오면 매개(회계 항등식 분해: 채용/이직/순증).
20. **counter-intuitive 독법** — 채용 ↑ 인데 고용 ↓ : 반대 방향 gradient 는 "없음"이 아니라 두 번째 헤드라인.
21. 불변성(invariance) 결과의 재해석 — "거래 특성이 설명 못함"은 표적 특성 주장의 대조군.

## F. 검정력 진단
22. MDE(80%) 를 귀무 SD 로 계산해 "미검출" 이 "없음" 인지 "볼 수 없음" 인지 구분.
23. 표본외 교차적합 — 표본내 분리가 예측으로 재현되는지(P-014: 둘 다 음의 R² — 정직 보고).
