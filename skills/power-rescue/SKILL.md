# academics:power-rescue — 설계 회복 다중경로 하네스

PI 가 20회 반복한 지시("포기하지 말고 더 적합한 방법론으로… 변수 전환·기준 변경·데이터 설계")의 절차판. 뜻은 **위음성 방지**이지 유의성 탐색이 아니다 — `references/guardrails.md` 를 먼저 읽는다.

## 절차
1. **약해진 것을 한 문장으로** 적는다: 어느 추정치(원장 id), 어느 리뷰·어느 변경 뒤에, 얼마에서 얼마로.
2. **원인 가설 나열** — 반사실 오염 / 대조풀 오염 / 표본 축소 / 분모 인공물 / 0 탈락 / 창 겹침 / 집계 수준 / 검정력 부족 / 실제 효과 없음. 마지막 가설도 항상 포함한다.
3. `references/design_levers.md` 에서 가설별 레버를 고르고 **순서**를 정한다(반사실 → 표본 → 결과변수 → 추론 → estimand). 한 번에 하나.
4. 레버마다 `iNN_<slug>.py` 하네스 스크립트(`references/harness_contract.md`, `scripts/emit_contract.py`). docstring 에 **예측을 먼저** 쓴다. 번호 충돌 확인.
5. 실행 → `verdict` 를 GO/PARTIAL/KILL 로. 등가성은 CI 로(`excess_ci` 저장).
6. **모든 결과를 RESULTS_LEDGER § 에 표로** — 유리·불리 함께. 불리한 결과 절을 비우지 않는다.
7. 채택 사양이 바뀌면: 사유를 경제·계량적으로 쓰고, 옛 사양은 원장 SUPERSEDED + 부록. 원고·표·그림·캡션 전파는 `academics:comment-dispose` 절차 5~7.
8. 회복이 안 되면 그렇게 쓴다. "not detected" 와 "absent" 를 구분하고 MDE 를 병기.

## 두 논문에서 실제로 결과를 바꾼 레버
| 약점 | 레버 | 변화 |
|---|---|---|
| 이질성 gradient 가 약함(z 2.19) | 조절변수 균형 매칭 + 반사실 오염 진단 | 0.48→0.71, z 3.96; 대조군 오염 0.311→0.035 |
| 이직 gradient 단독 미검출 | 쌍대비 + 결합 Mahalanobis RI | 채용−고용 +0.754 (z 4.56); 결합 p 0.0005 |
| 처치표본 부족 | 기업명 매칭 회수 | 283→379; 기각 설계 재점검 |
| 대조 풀에 유사처치 잔존(P-016) | clean pool 통일 | 잃은 검정력 회복 |
| 격자 문턱별 점검정 | sup-t 균일 밴드 + max-\|t\| | 꼬리 결과가 격자 전체에서 유지 |
| 사전추세가 결과 기준창과 겹침 | 비중첩 창(−36:−25) 재추정 | 초과 [−0.44, +0.09], ±0.71 등가성 |

## 바꾸지 못한 것(정직 보고의 예)
