# 주장 강도 어휘표 (리뷰 5~10 에서 실제로 교정된 표현)

| 쓰지 말 것 | 이유 | 대신 |
|---|---|---|
| "no effect", "absent", "precise zero" | 점추정으로 "없음" | "not detected" + MDE / "interval excludes an effect as large as X" (CI⊂±SESOI 일 때만 "equivalent") |
| "every specification is significant" | 부록에 미검출 사양이 있음 | "detected across the principal specifications … not detected when …" |
| "specific to hiring", "not in net employment" | 반대 방향 효과가 **검출**됨 | "the positive gradient **reverses** in net employment (−0.058, detected)" |
| "predicts more strongly than" | 표본외에서 실패 | "produces the clearest **detectable** heterogeneity among the dimensions we observe" |
| "organized by X rather than Y" | 전칭 | "…rather than by any Y we observe" |
| "must match on the moderator" | 일반명제 | "must balance the moderator **when it predicts untreated outcome dynamics**" |
| "cannot be affected by re-registration" | 보장 불가 | "does not use the reported acquisition count directly" |
| "paid at normal wages" | 작은 할인 배제 못함 | "no evidence of a large measured wage discount" |
| "carry no information about timing" | 상한이 헤드라인의 40% | "do not reveal a separate timing shift of comparable magnitude"; "largely accounted for" |
| "the excess attributable to treatment" | 인과 어법 | "the observed excess over the untreated null" |
| "pre-specified", "ex ante", "preregistered", "frozen" | 규칙 10 | "directional hypothesis" (사전등록 기록이 없으면) |
| "8.8 percent" (log 계수) | 단위 오류 | "0.088 log points (about 9 percent)"; 구간도 같은 단위 |
| "randomization inference" (위약 재표집) | 명명 과장 | "empirical placebo null", "placebo p" |
| "turnover", "separating far more" (이직 미검출) | 채널 미식별 | "gross worker flows"; 이직은 "not separately detected" |
| "Every mediator … is null" | 그것들은 mediator 가 아님 | "none of the **other** observable firm, transaction or sponsor characteristics" |
| "common sample, n = 301" (행마다 n 다름) | 라벨 오류 | "available sample by characteristic (181–301)" |
